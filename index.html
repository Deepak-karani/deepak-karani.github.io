AI SKINCARE / iOSMay 2026 → now

Pibu01

An AI skincare companion that turns a guided photo check-in into personalized insights and a routine you can follow. Built and shipped as an iOS app, with the analysis and product experience connected end to end.

What I built +

I built the entire app: the React Native and Expo interface, Supabase and PostgreSQL backend, and a multi-image analysis pipeline using Deno Edge Functions and Vertex AI. My work spans the flow from photo capture to analysis results, data integration, debugging, privacy safeguards, testing, and App Store delivery. I coordinate with teammates on marketing and business while owning the product engineering.

React Native / PostgreSQL / Vertex AI / Edge Functions

AGENT SYSTEMS / EVALUATIONJun 2026

UserSwarm02

AI personas explore a live website, attempt real tasks, and turn their browser sessions into structured UX reports. Screenshots ground the findings so a builder can trace feedback back to what actually happened.

What I built +

I built the backend agent infrastructure with FastAPI, an agent execution graph, and isolated Playwright sessions. The system orchestrates concurrent personas and produces structured reports from their interactions. I added code and LLM evaluations, human-review calibration, and Arize/OpenTelemetry tracing to inspect behavior and judge report quality, while handling rate limits, timeouts, and unsupported model claims.

FastAPI / Playwright / Claude / OpenTelemetry

FINTECH / CAL HACKSOct 2025

Kasha03

A social budgeting app for shared spending, live balances, and contextual financial coaching. It brings transaction data and collaborative features into one experience, and won the Visa track at Cal Hacks.

What I built +

As backend engineer, I designed APIs and shared-transaction data flows using FastAPI, Node.js, PostgreSQL, and Socket.io. I integrated five Visa APIs and supported real-time spending updates and an AI financial coach with long-context memory. My focus was connecting external services and keeping shared data useful across concurrent client events, then delivering a working demo with the team under the hackathon deadline.

FastAPI / Node.js / PostgreSQL / Socket.io

GEOSPATIAL / CRUZHACKSJan 2026

SlugRoute04

A weather-aware route optimizer that treats changing conditions as part of the journey. It combines live weather data with maps and route scoring to help people compare ways across campus.

What I built +

I integrated WindBorne weather data with Mapbox routing and geospatial scoring in a Next.js application. I also worked on authentication and model fallbacks so the experience could handle more than the ideal demo path. The project connected live data to a practical routing decision and won Best Use of WindBorne API and Best Use of ElevenLabs at CruzHacks.

Next.js / Mapbox / Gemini / Auth0

LOCAL AI / MULTIMODALMay 2026

Cortex05

A local AI workspace that brings multiple agents and streams of context into a shared interface. Built during the NVIDIA x ASUS hackathon at UCSC, it explores how agent coordination can work while keeping captured frames local.

What I built +

I implemented Express and Socket.io orchestration for seven parallel local agents, connecting multimodal inputs with real-time updates. I worked on privacy-conscious frame handling and added a deterministic fallback for demo reliability. The project used Nemotron and DGX Spark, giving me experience coordinating agent workflows across local inference, backend services, and an interactive interface.

Express / Socket.io / Nemotron / DGX Spark

ON-DEVICE AI / ANDROID2026

Roost06

An offline-first Android project that turns grocery receipts into a usable household inventory. Its dragon mascot gives the experience a playful identity while the data layer keeps the app grounded in what a household has on hand.

What I built +

I worked on the local data layer in Kotlin, including the Room/SQLite schema, data access objects, and repository. That work supported how receipt-derived information is stored and accessed without depending on a constant network connection. I also contributed to the brand, presentation website, and outreach, helping connect the technical prototype to a clear product story.

Kotlin / Jetpack Compose / Room / ML Kit
